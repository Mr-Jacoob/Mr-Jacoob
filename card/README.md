# 💳 ziyo&co — цифровая визитка

Одностраничный сайт-визитка: телефон, сайт, соцсети и ссылка на Revolut.
Всё в одном файле — `index.html`, без сборки и зависимостей.

## Как изменить данные

Все контакты лежат **прямо в разметке** `index.html` — их видно в коде и они
работают даже без JavaScript. Правь по `id`:

| Где | Что |
|---|---|
| `<a id="l-phone" href="tel:...">` и `id="a-call"` | номер телефона |
| `id="a-wa"` | WhatsApp — `https://wa.me/393513047421` |
| `id="a-tg"` | Telegram — `https://t.me/stephn_jons` |
| `id="a-rev"` | Revolut — `https://revolut.me/ziyodullorahmon` |
| `id="l-site"` | сайт — `https://ziyodullo.com` |
| `id="l-ig"` | Instagram — `https://instagram.com/rahmonjonov.zdl` |
| `id="l-gh"` | GitHub — `https://github.com/Mr-Jacoob` |
| `id="l-mail"` | почта — `mailto:...` |
| `data-brand` у `<main class="card">` | название — `ziyo&co` |
| `data-person` у `<main class="card">` | имя для сохранения в контакты |

Скрипт внизу файла ничего не хранит — он читает эти же значения из разметки
для копирования, `.vcf` и кнопки «Поделиться». Дублировать нигде не нужно.

## Фирменные цвета

Взяты из бренд-превью `ziyo&co` и объявлены в `:root`:

| Токен | Значение | Где |
|---|---|---|
| `--ink` | `#14171C` | фон страницы и карточки |
| `--paper` | `#EDEBE7` | кнопка Revolut |
| `--gold` | `#C9A227` | акцент: амперсанд, подпись роли, кнопка «Звонок», иконки при наведении |
| `--light` | `#F5F3EF` | основной текст |

Шрифт — Outfit (как в бренд-превью), номер телефона — JetBrains Mono.
Иконки WhatsApp и Telegram оставлены в своих цветах, чтобы их узнавали.

## Логотип

`card/mark.svg` — Z-монограмма золотом на `--ink`, она же иконка вкладки.
Та же фигура встроена в разметку как аватар (inline SVG, без запроса в сеть).
Чтобы поставить оригинальный знак из бренд-пака: положи `ziyo-mark.svg`
рядом и замени `mark.svg` + inline-SVG внутри `<div class="avatar-wrap">`.

## Что умеет

- Компактная раскладка — целиком помещается на экран телефона, без прокрутки
- Логотип, название и стек в одну строку сверху; номер отдельной строкой с копированием
- Кнопки «Звонок», WhatsApp и Telegram в ряд, широкая кнопка Revolut
- Плитки соцсетей: Website, Instagram, GitHub, E-mail (долгое нажатие копирует адрес)
- «В контакты» — скачивает `.vcf` для телефона
- «Поделиться» — системный share, с копированием ссылки как запасной вариант
- Аврора-фон, 3D-наклон карточки на десктопе
- На очень низких экранах (< 620px) сама прячет строку со стеком и подпись
- Уважает `prefers-reduced-motion`

## Как открыть

Просто открой `card/index.html` в браузере.

Публикация через GitHub Pages: **Settings → Pages → Deploy from a branch**,
после чего визитка будет доступна по адресу `https://mr-jacoob.github.io/Mr-Jacoob/card/`.
